# Catalogue image identity audit

Reviewed 1 November 2026. All 89 seed listings, their 89 original primary files and all 218 originally displayed gallery views were visually inspected on ten contact sheets. New manufacturer files were inspected separately after download. The corrected catalogue has 213 gallery views; 45 primary media tuples were replaced/promoted. This is an identity and reference-image audit, not verification of London Tech's physical stock or product authenticity.

## What changed

- Samsung Galaxy S26 Ultra no longer uses an Infinix phone. Its own five-lens rear, S Pen and finish-lineup imagery are recorded in the media manifest. The incorrectly labelled Galaxy tablet file was identified as S26 Ultra-family imagery and assigned to that phone family.
- Generic Galaxy tablet, iPad Pro and Apple Watch Series listings now show the correct device families. Their exact stocked generation/size remains unconfirmed, so the reference model is explicitly stated rather than inferred.
- The PITAKA case no longer shows laptops/phones without a case. The 72cm Pierre Cardin trolley no longer shows a backpack. Generic remote stock-camera and mixed-console seed primaries are replaced by their existing researched manufacturer photos.
- Single researched images now replace their legacy gallery rather than being padded with unrelated legacy extras. AirPods Max therefore loses the unrelated headphone photos. Repeated JBL and ThinkPad views are removed.
- Unsupported controller, generic case, magnetic power-bank and three-pack claims are narrowed to the product class actually shown. Truncated or inferred brand names are corrected (for example Chanel, Green Lion, Carolina Herrera, Lenovo and game publishers).
- Untouched old seed rows are repaired at database initialization, with a complete-record compare-and-set condition so concurrent stock/merchant edits win. The browser also repairs only exact historical name/image/gallery tuples. Custom primary photos, custom galleries and renamed merchant products remain authoritative.

## Limits and evidence

A manufacturer family photo may be shared by different sizes/finishes; it does not establish the selected storage, screen size, regional radio, condition, accessories, price or remaining stock. Generic listings expose a media note naming their reference family. The controller, generic magnetic power bank and generic clear/slim cases still need original shop model identification; their exact-model claims were removed. The retro handheld collection is a category photo, not an advertised bundle. TL620 remains a retailer-labelled reference, not a verified global Lenovo part number. The two generic Soundcore listings overlap in their reference family and need owner review before becoming distinct confirmed offers.

The table records what was actually visible. A source link supports the product/model reference and is not necessarily the original download URL for a pre-existing owner-supplied file. Rows without a link retain visually consistent owner/reference assets whose original download provenance is unavailable; no precise manufacturer claims were added for those rows. Full current galleries and per-view source/alternative text are in src/data/product-media.json. Original manufacturer files are kept unmodified; some new files are larger than the historical 1400-pixel web copies.

- The four reported wrong-category mappings are explicit tests, along with PITAKA and the trolley.
- Tests verify that price, stock and chosen configuration survive seed repairs, custom primary-only photos remain first, custom galleries/names win, and a concurrent persisted-record edit is not overwritten.
- Every corrected gallery decodes from a local asset and has no byte-identical repeats within that listing. The existing gallery/source test passes after these corrections.
- Run the image-index generator after catalogue media/name changes so image search uses the same current models.
