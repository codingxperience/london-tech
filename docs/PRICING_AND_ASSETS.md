# Catalogue and guide prices

Guide prices are owner-requested draft estimates in UGX, entered on 30 October 2026. They are starting points for review, not confirmed live offers. Exact capacity, model, generation, product condition, included accessories, wholesale cost and margin need store confirmation.

The primary storefront product names and layout were retained from current repository commit `ec27da6`. The supplied `london_assest.zip` contributes additional product imagery. Files and banners bearing unrelated store branding are not used in the storefront. The original London Tech white-backed logo remains the favicon/share identity.

Additional product photographs retained from the earlier repository are used for the expanded catalogue. Source model names can be ambiguous; confirm them in admin before publishing a confirmed offer. In particular, generic Galaxy tablets, Apple Watch and Soundcore entries request an exact model confirmation rather than inferring specifications from an image file name.

Price references consulted for a few anchors (retailers’ own listings, not London Tech selling prices):

- [UgaBuy storefront](https://ugabuy.online/) — iPhone 17 family, AirPods Max and iPad Pro examples.
- [Apple Store Uganda](https://applestoreuganda.com/?lang=en-US) — Apple catalogue and price range examples.
- [ARTHUR JBL catalogue](https://www.askarthur.biz/brands/jbl) — JBL Tune 770NC and PartyBox Stage 320 examples.
- [Nexus Computers iPhone catalogue](https://nexuscomputers.ug/product-category/smartphones/apple-iphone/) — iPhone configuration examples.

Remaining values are drafted estimates, not individually verified retailer quotes. Drafts live in `src/data/prices.js`. They have no artificial previous price or discount, and stock quantities are not invented. Administrator confirmation controls live ordering.
