# Catalogue and guide prices

Guide prices are draft estimates in UGX, entered on 30 October and 13 November 2026. They are starting points for review, not confirmed live offers. Exact capacity, model, generation, product condition, included accessories, wholesale cost and margin need store confirmation.

The primary storefront product names and layout were retained from current repository commit `ec27da6`. The supplied `london_assest.zip` contributes additional product imagery. Files and banners bearing unrelated store branding are not used in the storefront. The original London Tech white-backed logo remains the favicon/share identity.

Additional product photographs retained from the earlier repository are used for the expanded catalogue. Source model names can be ambiguous; confirm them in admin before publishing a confirmed offer. In particular, generic Galaxy tablets, Apple Watch and Soundcore entries request an exact model confirmation rather than inferring specifications from an image file name.

The retailer figures are comparison points for similar visible styles, not exact quotes for London Tech stock. All stockroom additions carry numeric guide prices with `priceConfirmed: false`; the storefront labels them “Guide price” and live ordering remains subject to store confirmation. No artificial previous price, discount or stock quantity is added. Existing merchant-confirmed prices remain untouched.
