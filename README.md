# London Tech

London Tech storefront built with React, TypeScript, Vite and Tailwind CSS.

## Development

Use Node.js 22 or newer and pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Production

```sh
pnpm build
```

Deploy the generated `dist/` directory. The original favicon, manifest, brand logo assets, and Open Graph / Twitter preview metadata are preserved. Images are stored directly in Git without Git LFS.
